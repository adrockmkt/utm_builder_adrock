# Spec 002 - Governed Links

## Goal

Evoluir o produto de gerador para catálogo governado de links.

## Scope

- `link pontual`
- `campanha`
- `grupo de ações`
- tabelas `utm_campaigns` e `utm_links`
- histórico, filtros, edição, exclusão lógica, duplicação
- usuários com perfis `admin`, `editor`, `viewer`

## Success

- cliente consegue entender o que cada link representa
- links deixam de nascer sem contexto
- leitura posterior no GA4 fica auditável
