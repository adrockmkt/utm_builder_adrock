# Spec 001 - Standalone Foundation

## Goal

Criar a primeira base destacável do UTM Builder fora do hub, mantendo o que já existe hoje de geração e validação.

## Scope

- app frontend standalone
- identidade própria do produto
- backend scaffold próprio
- docs próprios
- governança via specs

## Non-goals

- multi-tenant
- billing
- painel público
- persistência completa já implementada

## Success

- pasta pode virar repositório separado sem depender da documentação do hub
- módulo atual roda como app própria
- produto já comunica claramente sua futura evolução
